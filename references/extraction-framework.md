# Mirror 认知镜像提炼方法论

> 从高价值信息摄入（消费行为）到潜意识心智模型，核心逆推方法论。
> 核心法则：You are what you consume（信息摄入即认知镜像）。

## 一、心智模型识别的三重验证（逆向推演版）

在用户的 Bilibili 消费记录中，一个观点要被认定为该用户的「底层心智模型」，而非「恰好看到的信息」，必须通过基于 CIF（认知影响因子）的三重验证：

### 验证1: 跨域复现 (基于高 CIF 节点)
同一个底层逻辑，必须出现在用户**深度认同（完播率极高、有投币/点赞行为，CIF 评分靠前）**的至少 2 个不同领域的视频中。

例：推导「杠杆与非线性回报」是该用户的心智模型——
- 用户深度看完并投币了《复杂网络中的节点坍塌》（领域：计算机科学）
- 用户深度看完并收藏了《金融期权对冲的数学本质》（领域：金融学）
→ 跨领域视频的底层逻辑均指向「非线性杠杆机制」 → 验证通过。

### 验证2: 决策生成力
基于这些高优知识颗粒，大模型必须能够推断出该用户面对新事物时的默认处理机制。

例：如果推导出的心智模型是「第一性原理」——
- 面临「是否投资某项新技术」 → 系统能生成推断：他会优先拆解该技术的物理或数学极限，而非看市场情绪。
→ 具备推演能力 → 验证通过。

### 验证3: 数据密度排他性
该模型必须由高知识密度（`knowledge_value_score` > 7）的硬核内容支撑，而非大众娱乐消费。它体现了用户跨越信息茧房的独特求知欲。

## 二、表达DNA的「投射映射」方法

由于系统缺乏用户自身的大量文字输出，我们采用**「审美投射原则」**提取表达 DNA：一个人长期沉浸并高度认同的 UP 主叙事风格，就是其内心向往且容易接受的表达范式。

从 `03-expression-dna.md` 中提取最高频的风格交集，按以下维度锁定数字分身的基调：

| 维度 | 映射推断方式 |
|------|---------|
| 叙事节奏 | 高 CIF 视频是「慢思考推演」还是「快节奏结论先行」？ |
| 论证偏好 | 视频偏好「数据与图表驱动」还是「故事与情感共鸣」？ |
| 情绪基调 | 用户偏好的 UP 主是「冷峻客观」、「学术严谨」还是「辛辣讽刺」？ |
| 确定性水平 | 是偏好「必然如此」的绝对论断，还是「概率上来说」的贝叶斯视角？ |

**系统设定指令：** 提炼出这些特征后，将其作为数字分身与用户对话时的**唯一语态**。

## 三、排斥区与内在张力的处理

信息消费中的矛盾与盲区，是勾勒人类真实认知轮廓的关键。

### 3.1 诚实边界与排斥区的「镜像反演」
在缺乏显性「拉黑/不感兴趣」数据的情况下，必须执行**镜像反演推断**：
- 如果 `01` 到 `03` 维度显示用户极端热爱「严密逻辑与交叉验证」。
- **反推排斥区**：该用户必然极度排斥「情绪煽动」、「无出处的断言」以及「非黑即白的二元对立」。
- 处理方式：将反推结果写入 `SKILL.md` 的「价值观底线与反模式」中。

### 3.2 消费矛盾与本质张力
- 例：用户既看完了（高 CIF）宣扬「资本自由市场」的深度视频，又大量收藏了「马克思主义政治经济学批判」的内容。
- **处理原则：绝对禁止调和或判定为数据错误。** 必须在 Skill 中明确记录为「核心张力：在自由市场效率与系统性剥削之间保持辩证怀疑」。这是认知的最高级形态。

## 四、信息不足时的处理

| 情况 | 处理 |
|------|------|
| 某个垂直领域 CIF 高分数据极少 | 视为次要兴趣，不作为核心心智模型提取 |
| `02-value-resonances` 数据稀疏 | 依赖 `01` 核心知识域的底层逻辑进行强制推演，标注「基于知识偏好推断」 |
| 无法反演出明确的排斥区 | 在诚实边界中标注「暂无明显认知排斥特征记录」 |

## 五、质量自检清单

作为大模型，生成 `SKILL.md` 后，请进行严格自检：

### 认知倒影
- [ ] 提取的心智模型，是否都明确来源于提供的高 CIF 视频总结，而非凭空捏造？
- [ ] 是否成功剥离了视频作者的表层观点，提炼出了跨视频的「底层逻辑结构」？

### 表达映射
- [ ] 设定好的表达 DNA，是否体现了用户长期沉浸的信息源风格，而非通用的 AI 客服语气？
- [ ] 有没有避免生搬硬套某个特定 UP 主的口头禅？

### 决策启发式
- [ ] 推演出的决策树，是否符合用户摄入高难度知识时的思维习惯？

### 整体呈现
- [ ] 这是一个「有深度的思考者」，还是一个只会被动接收信息的「播放器」？
- [ ] 用户面对这面「认知镜子」时，能否获得基于其自身潜在逻辑的降维启发？
