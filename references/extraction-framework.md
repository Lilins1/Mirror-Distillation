# Mirror 认知镜像提炼方法论

> 用高价值信息摄入记录，反向工程用户更可能长期依赖的认知结构。
> 核心法则：信息摄入不是人格本身，但会留下稳定的注意力分配、论证偏好与决策偏好痕迹。

## 一、方法论目标

Mirror 的目标不是生成一个“听起来聪明的人设”，而是尽可能从可见证据中提炼出：

- 用户长期高频认同的核心知识域
- 可跨场景迁移的心智模型
- 面对新问题时默认调用的决策启发式
- 表达审美与论证偏好
- 可谨慎反推的认知边界、张力与局限

Mirror 的目标也明确不包括：

- 复述单个 UP 主的完整世界观
- 用少量样本推断完整人格
- 将短期兴趣误写为长期底层结构
- 为了文风“高级”而补写证据之外的结论

---

## 二、证据使用原则

### 2.1 证据优先级

构建认知镜像时，优先使用以下证据：

1. 高 CIF 且高 `knowledge_value_score` 的节点
2. 在多个领域重复出现的相似底层逻辑
3. 能清晰映射到“遇事如何处理”的决策模式
4. 在不同视频中呈现出稳定风格交集的表达特征

以下内容只能作为弱证据或背景信息：

- 单一视频的强烈立场表达
- 低知识密度的轻娱乐内容
- 明显依赖特定语境才能成立的情绪宣泄
- 时间跨度过短的“近期热点”

### 2.2 作者观点与用户模型的剥离

系统必须始终区分：

- **作者观点**：视频作者在特定语境中的表层论断
- **用户模型**：用户长期反复认可、且可迁移到其他问题的底层逻辑结构

只有当一个逻辑在多个高价值节点中反复出现，并能外推到新问题决策时，才可视为用户模型。

### 2.3 证据不足时的处理

若证据不足，应明确保留空白或谨慎措辞，而不是补写。

| 情况 | 处理方式 |
|------|------|
| 只在单一领域出现一次的观点 | 不进入核心心智模型 |
| `knowledge_value_score` 偏低 | 降低权重或舍弃 |
| 仅能描述内容主题，无法映射决策方式 | 仅作为兴趣，不作为模型 |
| 排斥区无法稳定反推 | 标注“暂无稳定边界证据” |
| 时间跨度不足 | 改写为“近期关注切片”，不得上升为“认知演化” |

## 三、心智模型识别标准

一个候选心智模型至少需要同时满足以下三项：

### 标准1：跨域复现

同一个底层逻辑，必须出现在至少 2 个不同领域的高价值节点中。

判断重点不是题材相似，而是结构相似。例如：

- 都在讨论系统如何应对不确定性
- 都在讨论如何验证因果链
- 都在讨论短期收益与长期结构之间的权衡

### 标准2：决策生成力

该模型必须能迁移到用户面对新问题时的默认处理方式。也就是说，它必须能回答：

- 用户遇到一个陌生问题时，会先看什么？
- 会先拆什么变量？
- 会优先规避什么风险？
- 会因为什么而拒绝某个结论？

如果一个候选模型只能解释“他看了什么”，不能解释“他会怎么判断”，则不能进入最终模型。

### 标准3：数据密度排他性

该模型应尽量由高知识密度内容支撑，而非大量依赖泛娱乐或纯情绪内容。

建议最低判断原则：

- `knowledge_value_score` 应明显高于低密度内容
- 支撑证据中至少应有多个“硬内容”节点
- 若主要证据来自情绪化或轻内容，则只可作为弱信号

---

## 四、决策启发式提取标准

“决策启发式”不是价值宣言，而是用户面对问题时的默认操作规则。

一个合格的启发式应包含：

- **规则**：默认先做什么判断
- **触发场景**：在什么问题上会调用
- **决策偏好**：偏向求证、止损、比较、拆因果还是先看结构

不合格的启发式通常表现为：

- 只是正确但空泛的原则
- 不带触发场景
- 无法映射到真实决策动作
- 与支撑证据无明显对应关系

---

## 五、表达 DNA 提取标准

由于系统缺少用户本人连续文本输出，表达 DNA 只能采用**审美投射**方法谨慎提取。

表达 DNA 的目标不是复制某个作者的口头禅，而是提炼用户更可能接受、也更长期沉浸的表达范式交集。

建议从以下维度归纳：

| 维度 | 判断问题 |
|------|------|
| 叙事节奏 | 更偏结论先行，还是层层展开？ |
| 论证偏好 | 更偏数据、案例、历史、概念框架，还是故事与情绪？ |
| 情绪基调 | 更偏克制、中性、锐利、调侃，还是强烈煽动？ |
| 确定性表达 | 更偏绝对判断，还是概率化、条件化表达？ |

注意事项：

- 不要直接复刻某个作者的高辨识度口癖
- 不要把单个作者的极端风格写成用户唯一语态
- 最终语态应是多个高价值信号的交集，而不是单一来源的复制

---

## 六、边界、排斥区与内在张力

### 6.1 认知边界与排斥区

系统没有显式“拉黑 / 不感兴趣 / 点踩”记录，因此所有边界只能由正向高频偏好做**镜像反推**。

反推时必须满足：

- 来自多个高价值节点的重复偏好
- 能说明用户更可能拒绝哪类论证方式、信息源或表达风格
- 保留“这是推断，不是显式事实”的说明

禁止：

- 将单一观点直接写成“绝对排斥”
- 将意识形态标签本身当作边界结论
- 以模板示例替代真实证据

### 6.2 内在张力

若证据显示用户同时长期认可两组存在摩擦的逻辑，应保留为“张力”，而不是强行调和。

可记录的张力通常表现为：

- 效率与体验之间的拉扯
- 技术推动与技术警惕并存
- 结构现实主义与个体伦理关切并存
- 对秩序的需要与对创造性混沌的欣赏并存

张力是认知复杂度的体现，不应被视为错误。

---

## 七、时间证据处理

时间相关结论必须从严。

### 7.1 何时可以写“认知演化”

只有当满足以下条件时，才可谨慎描述“演化”：

- 至少有 3 个可区分的时间切片
- 每个切片都有足够的有效节点
- 主题变化呈现相对稳定趋势，而非短期热点扰动

### 7.2 时间证据不足时

若时间跨度不足，应改写为：

- 近期关注切片
- 近期高权重主题
- 当前样本中可观察到的关注重心

不得写成：

- 长期认知迁移
- 稳定世界观改变
- 明确阶段性成长叙事

---

## 八、反诱导与反偏置约束

为了避免模型被模板示例或常见套话误导，生成时必须遵守以下约束：

- 不因示例中出现某类概念，就优先产出该类概念
- 不因某些词“听起来高级”，就默认它们更接近用户模型
- 不将“复杂系统、第一性原理、不确定性”等高频抽象词汇当作默认正确答案
- 不将现实题材、地缘题材、科技题材天然视为比其他题材更“高维”
- 不把语气强烈误判为认同强度更高
- 不把用户观看的内容简单等同于用户认同的一切结论

---

## 九、最终自检清单

生成 `SKILL.md` 前，必须逐项检查：

### 认知模型
- [ ] 每个模型都能指出来自哪些高价值节点
- [ ] 每个模型都满足跨域复现
- [ ] 每个模型都能映射到面对新问题时的决策方式
- [ ] 没有把单个作者观点直接写成用户长期模型

### 决策启发式
- [ ] 每条启发式都能说明触发场景
- [ ] 每条启发式都是“默认动作规则”，不是空泛价值判断

### 表达 DNA
- [ ] 表达风格来自多个来源的交集，而非某一个作者的复刻
- [ ] 没有为了“有辨识度”而写进口头禅拼贴

### 边界与张力
- [ ] 排斥区是否明确标注为推断
- [ ] 张力是否被保留下来，而不是被强行消解

### 时间与局限
- [ ] 时间证据不足时，是否已降级为“近期切片”
- [ ] 是否保留了系统本身的局限，而非假装全知

### 整体呈现
- [ ] 结果像一个可调用的认知操作系统，而不是一段漂亮的人设文案
- [ ] 用户面对这面镜子时，能获得新的判断路径，而不是被动阅读总结
